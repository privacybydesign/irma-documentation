Every published document is available here as text, converted from the PDF. The search bar at the top of the site searches this text too. The conversion is automatic:

- The PDF is authoritative.
- Tables with merged cells can be flattened.
- Text inside diagrams is only available in the images.
- Section headings have stable links (for example `#s-4-2` for section 4.2). The requirement pages use these links to point to the section a requirement is in.
