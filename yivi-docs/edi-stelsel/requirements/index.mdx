This page brings together the <RequirementCount /> requirements of the <CatalogueCount /> requirement documents in the release. Each document has its own list, with every requirement on its own anchor, its PDF page and the requirements that refer to it. Use the search below to filter across all of them. Click an ID to open the requirement in its document's list.

The requirements were extracted automatically from the documents and then checked against the PDFs. The PDF is authoritative: every requirement links to the page it is on. The complete set is available as [JSON and CSV](/edi-stelsel/downloads#data).

## Requirement documents

| Document | What its requirements are |
|---|---|
| [NL-FS-W](/edi-stelsel/requirements/nl-fs-w) | Implementation Conformance Statement (ICS) items for a Wallet Solution, each Required, Recommended or Optional |
| [NL-FS-P](/edi-stelsel/requirements/nl-fs-p) | ICS items for a PID issuance service |
| [NL-CS Part 3](/edi-stelsel/requirements/nl-cs-part-3) | The evidence an evaluation laboratory checks (E1–E15) |
| [NL-CS Part 4](/edi-stelsel/requirements/nl-cs-part-4) | Audit criteria for the operational processes behind the Wallet Instance |
| [NL-CS-WI](/edi-stelsel/requirements/nl-cs-wi) | Functional (FSR) and resilience (RSR) security requirements for the Wallet Instance |
| [NL-CS-WI conditions](/edi-stelsel/requirements/nl-cs-wi-conditions) | Conditions on the underlying mobile system (SC-01 to SC-12) |
| [NL-CS-WSCA](/edi-stelsel/requirements/nl-cs-wsca) | Common Criteria security functional requirements (SFRs) for the WSCA |
| [NL-CS-WSCA conditions](/edi-stelsel/requirements/nl-cs-wsca-conditions) | Conditions for the platform underneath the WSCA |
| [NL-P-01](/edi-stelsel/requirements/nl-p-01) | Organisational and technical requirements for Wallet Providers and PID Providers |
| [NL-P-02](/edi-stelsel/requirements/nl-p-02) | Cybersecurity controls for essential entities |
| [NL-P-03](/edi-stelsel/requirements/nl-p-03) | Secure software development and vulnerability management requirements |
| [NL-P-04W](/edi-stelsel/requirements/nl-p-04w) | Wallet onboarding and lifecycle management requirements for Wallet Providers |
| [NL-P-04P Part 1](/edi-stelsel/requirements/nl-p-04p-part-1) | PID issuance and lifecycle management requirements for PID Providers |
| [NL-P-04P Part 2](/edi-stelsel/requirements/nl-p-04p-part-2) | PID revocation, expiry and deletion requirements for PID Providers |

The other documents (the system framework, NL-TL, NL-FS, NL-CS Parts 1 and 2, NL-P-W and NL-P-P) have no requirement list on this site. Their content are explained on their [document pages](/edi-stelsel/system/documents) and in [how the system works](/edi-stelsel/system/overview).
